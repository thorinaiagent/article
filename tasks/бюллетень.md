# Бюллетень (Бюлль)

Еженедельная (иногда раз в 2–3 недели) подборка новостей о компании. Голос —
общий для внутрикома, см. `../voice/внутриком.md`.

У Бюлля два артефакта:

1. **Рассылка** — развёрнутые новости по рубрикам.
2. **Короткий пост в телегу** — хайлайты со ссылкой на рассылку.

## Рассылка: структура

Устойчивый порядок рубрик (появляются не все сразу, но порядок держим):

**События → Выступления → Технологизация → Шеринг знаний → Награды / Важное →
Полезности → Приятности → Доброе дело.**

«Приятности» и «Доброе дело» — всегда в хвосте (тёплая посадка). Новости внутри
разделяются линией `________________`.

Каждая новость состоит из трёх частей:

- **Игровой заголовок** — каламбур, отсылка к поп-культуре/мему или имя робота.
- **Текст** — 3–6 строк, суть без воды, честно.
- **Кнопка** — глагол-призыв в тон новости (см. палитру ниже).

## Пост в телегу: структура

1. **Заход-приветствие** с новой метафорой Бюлля (обязательно, см. ниже).
2. **Буллиты хайлайтов** — одна новость = одно предложение, без деталей.
   Маркер плавает по выпускам (`💡`, `✔️`, `•`) — главное, единый внутри поста.
3. **Пожелание в конце** — опционально, тёплое: «Хорошей недели — и побольше
   поводов попасть в следующие выпуски».

## Заход — фирменный приём

Каждый выпуск открывается **свежей метафорой Бюлля**. Дословно между выпусками
не повторять — заход всегда новый. Рабочие приёмы:

- **Бюлль как живое существо / явление природы:**
  - «Молодой Бюлль прилетел со стороны моря, сел на ветку и начал радостно
    чирикать»;
  - «В высокой зелёной траве, поблёскивая на солнце, лежит новый Бюлль»;
  - «Яркий летний Бюлль солнечным зайчиком прыгает по экранам».
- **Бюлль как еда («испекли / приготовили»):**
  - «Испекли для вас свежий Бюлль»;
  - «Испекли свежий кулич, ой, то есть Бюлль — внутри сдобный опыт и сладкие
    новости».
- **Ритуал начала недели:**
  - «По традиции начинаем неделю с Бюлля»;
  - «Ловите хайлайты из свежего Бюлля».
- **Стилизация под жанр** (для отдельных новостей): анекдот («Заходят как-то
  четыре робота на TechWeek…»), песня («Под крылом самолёта о чём-то поёт…»),
  былина («Остановись, путник…»), рэп («На связи MC Святые Свитки…»).

## Кнопки — палитра глаголов

Императив/инфинитив в тон новости: получить VPN · Поймать спокойствие ·
Прокачать фидбэк · Иду гонять агента · Насыпать звёзды · Выразить респект ·
Залутать подборку · Хабануть · Залипнуть · Твори добро · У меня лапки ·
Покрутить токены · Сдвинуть рамки. В телеге помечается «Кнопка: …».

## Игровые заголовки — палитра приёмов

Каламбур или отсылка: «Один VPN, чтобы править всеми» (Толкин), «Выставка
достижений научного хозяйства» (ВДНХ), «Менеджер по имени Клод», «Что у LLM в
карманцах?», «Техосмотр агентов», «Агенты под надзором», «Магистр Маша Кияшко».

## Чего избегать

- дублей захода между выпусками;
- деталей в буллитах хайлайт-поста (суть — одним предложением);
- партнёрского пафоса и служебного «сырья» в тексте (см. `../voice/внутриком.md`).
