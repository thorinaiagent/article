# red_mad_robot — агент-редактор

Репозиторий правил редактуры red_mad_robot. Claude Code читает эти правила сам
при запуске в папке репо и правит по ним тексты: тон, стиль, структура, форматы.
Заучивать ничего не нужно — открываешь репо и ставишь задачу обычными словами.

## Быстрый старт

1. Склонируй репозиторий и открой его папку.
2. Установи Claude Code ([claude.ai/code](https://claude.ai/code)) и запусти
   `claude` внутри папки репо.
3. Скажи, что нужно: «отредактируй этот текст», «напиши пост в _rnd», «собери
   выпуск Бюллетеня», «собери статью из транскрипта». Правила подхватятся сами.

Подробный онбординг для редакторов — в [ONBOARDING.md](ONBOARDING.md).

## Карта репозитория

```
CLAUDE.md            роутер: правила, действующие всегда, и таблица «задача → файл»
redpolitika.md       официальная редполитика: тон, канцелярит, оформление, написание
voice/               как звучат тексты
  как-писать-и-редактировать.md   принципы письма и правки (грузится всегда)
  голос-на-хабре.md               как звучат статьи блога на Хабре
  внутриком.md                    голос внутренних коммуникаций
tasks/               форматы под конкретные задачи
  бюллетень.md                    рассылка «Бюллетень» и хайлайт-пост
  анонс-выпуска.md                тизер-пост под анонс дайджеста или рубрики
  пост-rnd.md                     пост в R&D-канал _rnd
  сборка-из-фактуры.md            сборка нового текста из заметок и транскриптов
refaktoring-articles/  скилл редактуры статьи (SKILL.md + сборка DOCX)
examples/            живые тексты и пары «до/после» для калибровки голоса
```

## Что агент умеет

- вычитать и отредактировать статью или пост по редполитике и голосу площадки;
- собрать новый текст из фактуры — заметок, транскрипта созвона, тезисов;
- пост в `_rnd`, выпуск «Бюллетеня», анонс рубрики, внутренние тексты.

## Как он правит

- минимально: сохраняет голос, ритм и факты автора, трогает только то, что
  нарушает правила или делает текст хуже;
- называет проблемы прямо, без пустых похвал;
- не выдумывает фактуру: цифру без источника или оборванную логику помечает
  вопросом для автора;
- спорную стилевую правку предлагает и объясняет, а не меняет молча.

## Правила, которые действуют всегда

- название компании — строго `red_mad_robot`: строчные буквы, нижние
  подчёркивания;
- буква «ё» обязательна;
- пишем позитивно и по делу, без канцелярита, маркетинговых штампов и рамок
  через «не».

Полный свод — в [CLAUDE.md](CLAUDE.md) и [redpolitika.md](redpolitika.md).
